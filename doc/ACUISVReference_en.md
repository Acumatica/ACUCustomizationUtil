Acumatica Customization Utility is a console utility designed to automate the workflow of customization development for Acumatica ERP.
Acumatica Customization Utility implements an intuitive and well-structured system of commands and options that allow you to conveniently perform the necessary actions when creating and maintaining Acumatica ERP customization packages. 

Acumatica Customization Utility supports such functionality:
 - Obtaining an installation image, deploying and uninstalling Acumatica ERP;
 - Installing, upgrading, or uninstalling an Acumatica instance;
 - Uploading, downloading, publishing, or unpublishing a customization;
 - Retrieving customization source code, building an extension library, making a customization package;
 
Acumatica Customization Utility allows developers to control and flexibly manage how an application executes commands using configuration files. Configuration files are in JSON format, with parameter names that are exactly the same as the corresponding option names. 
The ability to save a configuration file to a repository as part of a project allows you to quickly restore the environment to continue working on the project when working in teams.

Using Acumatica Customization Utility to automate the customization development workflow allows developers to significantly reduce the time spent on routine operations, minimize the number of errors and minimize the time spent on development in general.
