Acumatica Customization Utility - консольная утилита, предназначенная для автоматизации рабочего процесса разработки кастомизаций для ERP Acumatica.
Acumatica Customization Utility реализует интуитивно понятную и хорошо структурированную по функциональному назначению систему команд и опций, позволяющих удобно выполнять необходимые действия при создании и сопровождении  пакетов кастомизаций ERP Acumatica. 

Acumatica Customization Utility поддерживает такую функциональность:
 - Получение инсталляционного образа, развертывание и удаление ERP Acumatica;
 - Установка, обновление или удаление Acumatica instance;
 - Загрузка, получение, публикация или депубликация кастомизации;
 - Получение исходного кода кастомизации, сборка библиотеки расширения, сборка пакета кастомизации;
 
Acumatica Customization Utility позволяет разработчикам контролировать и гибко управлять тем, как приложение выполняет команды с помощью файлов конфигурации. Файлы конфигурации имеют формат JSON, имена параметров полностью одинаковы с названиями соотвествующих опций. 
Возможность сохранить файл конфигурации в репозитории как часть проекта позволяет быстро восстанавливать рабочее окружение для продолжения работы над проектом при командной работе.

Использование разработчиками Acumatica Customization Utility для автоматизации рабочего процесса разработки кастомизации позволяет значительно уменьшить время выполнения рутинных операций, минимизировать количество ошибок и сократить время, затрачиваемое на разработку в целом.
